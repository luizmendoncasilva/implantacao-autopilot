Loading/Available/Unavailable reaproveitam o Indicador Calculado recomposto (ver exploracao-origem.html). As 3 alternativas de "não aplicável" são composições locais (prefixo xn-) — nenhuma foi incorporada a um componente compartilhado do Cockpit.
Exploração — Estado Não Aplicável
Alternativas visuais para o quarto estado do Indicador Calculado — trilha Fiscal, aba Federais (INSS patronal fora do DAS).
Auditoria dos padrões existentes
Nenhum componente do Cockpit representa hoje "não aplicável" para um campo individual. .empty-state é dimensionado para telas/seções inteiras vazias — descartado. O precedente mais próximo é o traço "—" para "sem valor" e o texto discreto de .field-value.empty — mas ambos comunicam ausência, não "não se aplica por regra de negócio", que é semanticamente diferente.
Alternativa A — Texto secundário discreto
O valor vira um texto simples, peso normal (não itálico). A origem continua visível, com o mesmo .badge-neutral de sempre.
